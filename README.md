# Система управления товраами и заказами

## Описание проекта
Приложение для управления товарами и заказми в магазин. Разарботано на платформе **AvaloniaUL** с использованием **Entiti Framework Core** и **PostgreSql**.

## Роли пользователей
**Администратор** - Полный доступ: CRUD товаров, управление заказами, фильтрация, сортировка 
**Менеджер** -  Просмотр товаров (фильтрация, сортировка), просмотр заказов
**Клиент** - Просмотр каталога товаров 
**Гость** - Просмотр каталога без авторизации

## Товары
- Просотр списка
- Добавление нового товара
- Редактирование товара
- Удаление товара (с проверкой наличия в заказах)
- Удаление товара (с проверкой наличия в заказах)

## Заказы
- Просотр списка
- Добавление нового товара
- Редактирование товара
- Удаление товара (с проверкой наличия в заказах)
- Удаление товара (с проверкой наличия в заказах)

## Авторизация
- Вход по логину и паролю
- Вход как гость
- Разграничение доступа по ролям
